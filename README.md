# Lumen — Telegram Mini App: парсер заказов на лендинги

Тёмный интерфейс с «жидким стеклом», 6 площадок в одной ленте, подписка 270 ₽/мес через Telegram Stars, профиль с обводками аватара, чаты (друзья, группы, поддержка) и привязка своих аккаунтов.

## Площадки (6)

| Площадка | Как парсится | Что даёт |
|---|---|---|
| **Kwork** | JSON `stateData` со страниц «Биржи» (категории «Разработка сайтов» и «Дизайн») | заказы с бюджетом |
| **FL.ru** | официальные RSS (Дизайн, Сайты) | заказы |
| **Freelance.ru** | HTML ленты заданий | заказы |
| **Pchel.net** | HTML категорий (веб-дизайн, сайты под ключ, вёрстка) | заказы |
| **Telegram** | веб-превью `t.me/s/<канал>` (11 каналов) + личные чаты через привязанный аккаунт | посты с контактами заказчиков |
| **2ГИС** | Places API: компании в нише **без сайта** | холодные лиды на лендинг (нужен `TWOGIS_KEY`) |

Habr Freelance закрыт (404), Weblancer и Freelancehunt режут ботов (403), поэтому их нет в списке.
Фильтр релевантности (`server/src/parsers/relevance.ts`) оставляет веб-дизайн и лендинги и отсекает самопиар, SEO, карточки маркетплейсов и т.п.

## Запуск локально

```bash
cp .env.example .env
npm install
npm run dev:server   # API + парсеры + бот  (порт из .env, PORT)
npm run dev:web      # фронт http://localhost:5180
```

При `DEV_AUTH=1` вход работает без Telegram: dev-пользователь становится админом, плюс создаются 3 демо-юзера для чатов. Оплату можно «симулировать».
Проверить парсеры разово: `npm run parse:once -w server` (или `… -- kwork`).

## Бесплатно на Render

1. Зарегистрируйтесь на [render.com](https://render.com) через GitHub.
2. **New → Blueprint** → выберите репозиторий `blago-ceo/lumen` → Render прочитает `render.yaml`.
3. Заполните поля: `BOT_TOKEN` (от @BotFather), `ADMIN_IDS` (свой Telegram ID из @userinfobot), `ANTHROPIC_API_KEY` — по желанию.
4. **Apply** — через несколько минут сайт будет на `https://lumen-xxxx.onrender.com`. Адрес сам подставится в кнопку бота.

Важно: один и тот же бот нельзя одновременно запускать и на Render, и у себя на компьютере — Telegram отдаёт сообщения только одному. Ограничения бесплатного тарифа: сервис засыпает через 15 минут без посетителей (первое открытие ~минута), база обнуляется при каждом перезапуске.

## В продакшен

1. Создай бота у @BotFather, затем `/newapp` или Bot Settings → Menu Button с адресом `WEBAPP_URL` (нужен HTTPS).
2. Заполни `.env`: `BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_IDS`, длинный `APP_SECRET`, **`DEV_AUTH=0`**.
3. `npm run build`, затем `npm start`: сервер отдаёт собранный фронт и API с одного порта.
4. Опционально: `TG_API_ID`/`TG_API_HASH` (my.telegram.org) для привязки Telegram-аккаунтов и `TWOGIS_KEY` для 2ГИС.

### Оплата
Telegram требует, чтобы цифровые товары в Mini Apps продавались **только за Stars**. Инвойс создаётся с `subscription_period = 30 дней`, Telegram продлевает его сам. 270 ₽ — цена на витрине, реальная цена задаётся в `PRICE_STARS` (по умолчанию 180 ⭐).

## Агрегатор аккаунтов
- **Telegram**: полноценный вход (номер → код → 2FA). Сессия хранится в БД, зашифрованная AES-256-GCM. Пользователь выбирает свои чаты-источники, новые сообщения из них попадают в его личную ленту, и на заказ можно ответить от своего аккаунта (одно сообщение вручную, без рассылок).
- **Kwork / FL / Freelance.ru / Pchel**: открытого API нет, поэтому привязка идёт по публичному профилю (сервер проверяет, что профиль существует). Заказы этих бирж уже приходят через парсер.

## Структура
```
server/src
  index.ts          Fastify, статика, WebSocket
  db.ts             SQLite (node:sqlite, без нативных зависимостей)
  auth.ts           проверка initData Telegram, токены, Pro
  bot.ts            grammY: /start, Stars-подписка, пуши о лендингах
  parsers/          6 парсеров + скоринг + планировщик
  lib/tgUser.ts     GramJS: личные Telegram-аккаунты
  routes/           core (профиль, лента, оплата), accounts, chat
web/src
  styles/global.css стекло, аврора, обводки, баннеры
  screens/          Feed, LeadSheet, Paywall, Chats, ChatRoom, Hub, Profile
```
